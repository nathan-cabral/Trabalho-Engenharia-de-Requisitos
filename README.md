### Sistema de Achados e Perdidos

  Projeto desenvolvido para a disciplina de Engenharia de Requisitos, com o objetivo de realizar o levantamento, análise, documentação e implementação de um sistema de gerenciamento de objetos perdidos e encontrados.
  Além da documentação dos requisitos, o projeto contará com uma implementação funcional utilizando Java, aplicando conceitos de Programação Orientada a Objetos (POO).
  O sistema será executado inicialmente através do terminal.

--> Sobre o Projeto

  O sistema de Achados e Perdidos tem como objetivo facilitar o cadastro, gerenciamento e consulta de objetos que foram encontrados ou perdidos.
  Através do sistema, será possível registrar informações sobre objetos, consultar itens cadastrados e gerenciar possíveis correspondências entre objetos perdidos e encontrados.
  O projeto busca simular um sistema real, aplicando durante seu desenvolvimento conceitos estudados na disciplina de Engenharia de Requisitos e conhecimentos de programação orientada a objetos.

--> Objetivos
  Desenvolver a documentação de requisitos do sistema;
  Identificar os principais atores envolvidos;
  Levantar requisitos funcionais e não funcionais;
  Criar casos de uso;
  Modelar o sistema utilizando diagramas UML;
  Implementar uma versão funcional do sistema;
  Aplicar conceitos de Programação Orientada a Objetos;
  Criar uma aplicação executável através do terminal.

--> Tecnologias Utilizadas
  Java
  Programação Orientada a Objetos (POO)
  UML
  Git
  GitHub

  Inicialmente, o projeto não utilizará banco de dados ou interface gráfica, sendo executado diretamente pelo terminal.

--> Funcionalidades Previstas

  O sistema poderá possuir funcionalidades como:

  Cadastro de objetos perdidos;
  Cadastro de objetos encontrados;
  Consulta de objetos cadastrados;
  Busca de objetos por nome ou categoria;
  Alteração do status de um objeto;
  Registro de devolução de objetos;
  Remoção de registros;
  Listagem de objetos perdidos;
  Listagem de objetos encontrados.
  
--> Usuários do Sistema

  O sistema poderá possuir diferentes tipos de usuários, dependendo da evolução do projeto.

  Usuário/Aluno
  Responsável por:

    Registrar objetos perdidos;
    Consultar objetos encontrados;
    Buscar informações sobre objetos cadastrados.

  Administrador
  Responsável por:

    Gerenciar os registros do sistema;
    Alterar informações de objetos;
    Remover registros incorretos;
    Confirmar a devolução de objetos.
